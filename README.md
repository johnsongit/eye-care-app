# 健康小助手 (Eye Care Assistant)

Windows 电脑护眼桌面应用（Electron）。

## 功能
- **防蓝光模式**：屏幕暖色滤镜，5 档强度；持续开启或按时间段定时开启（支持跨午夜）。
- **豆沙绿护眼**：系统窗口背景改为豆沙绿 (204,232,207)，记事本/Word/WPS 等生效，关闭后恢复。
- **定时休息**：连续使用达到间隔（15 分钟 ~ 3 小时）后弹窗提醒，可开始 5 分钟休息倒计时；离开 5 分钟或锁屏自动重新计时。
- **定时关机**：每天到点提醒关机，或自动关机（60 秒内可取消）。
- **全屏检测**：全屏时可自动退出防蓝光 / 暂停弹窗提醒。
- 关闭按钮最小化到托盘；托盘菜单可快捷开关、设置开机自启。

## 开发
```powershell
npm install
npm start          # 运行
npm run dist       # 打包 dist/EyeCare-Setup-*.exe 与 portable exe
```

调试环境变量：`EYECARE_DRY_RUN=1` 不真正关机；`EYECARE_MINUTE_MS=1000` 把 1 分钟加速为 1 秒。
